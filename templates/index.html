System Architecture & Pipeline

End-to-end classification methodology

1. Ingestion

Gmail REST API v1 fetches email headers and multipart payload using OAuth 2.0 readonly permissions.

2. Preprocessing

BeautifulSoup strips HTML tags; regex removes whitespace, invisible Unicode (zero-width characters), and normalizes text.

3. Vectorization

TfidfVectorizer transforms preprocessed text into sparse numerical vectors with English stop words filter.

4. Inference

Multinomial Naive Bayes computes log likelihood and posterior class probabilities with Laplace smoothing.
